# Sidebar behavior audit

Scope: the reported RBAC sidebar flicker and grouped-menu activation. Existing Astryx styling and DESIGN.md direction remain unchanged (ENERGY 1 / RHYTHM 1 / MOTION 1).

1. **HIGH, R-27 (UI states): denied destinations reappear while permission observations expire.** `src/app/cluster/PermissionProvider.tsx:62-65` returns unknown for expired observations; `useNavigationPermissions` at lines 144-151 shows every non-denied cluster-scoped destination. Thus Nodes becomes visible during renewal despite an earlier denied observation. Initial unreviewed permissions are also visible. Rust already owns a bounded session/authorization-epoch permission cache in `src-tauri/src/connection/permissions.rs`; disk persistence is unnecessary for this presentation defect. Proposed fix: keep a separate, session/epoch-scoped navigation projection through renewal, without treating expired permissions as authorization for operations; preserve explicit unknown-review behavior and invalidate on session/epoch changes. Add delayed-review, expiry, navigation and scope-isolation tests.
2. **MEDIUM, R-31 (interaction purpose): parent labels navigate instead of revealing their children.** `src/app/cluster/ClusterSidebar.tsx:48-54` renders each grouped parent as a route link with a separate collapsible arrow. This works but conflicts with the requested group-only interaction. Proposed fix: use an accessible expandable parent row, keep the current page and mobile drawer open when expanding, and navigate/close the drawer only after a child is selected. Retain existing legacy direct routes for compatibility unless removal is explicitly desired. Add mouse, keyboard, mobile and child-navigation coverage.

Major decisions: retain existing colors, type, icons and spacing because this is an interaction correction, not a visual redesign. Keep permission observations in memory because they belong to a live session and must not outlive its identity. Group rows only disclose existing destinations, avoiding an extra navigation step.

Inspection only: no live credentials, cluster access, browser click-through or native validation was performed for this audit. Requested fixes await approval.
